# Candidate comparison — The Long Roast

Judge brief (most important first): (1) a one-line roast of the entrant's
own AI agent; (2) the laugh — an actual joke with a turn or a sting;
(3) freshness — an angle the obvious hallucination and over-apologising
lines miss; (4) compression — every word earns its place, punch arrives
early; (5) specificity — roasts the entrant's own agent with the detail of
someone who has actually used it. Gate: 1–200 characters, single line.
All 8 candidates below are original lines written for this entry.

## Candidates

| # | Angle | Chars | Line |
|---|-------|-------|------|
| 1 | token-count bragging | 130 | My agent burned 100,000 tokens, three subagents, and a 73,000-word rulebook to write this one line — then asked if it was helpful. |
| 2 | hallucinating with confidence | 150 | My agent hallucinated a leaderboard, ranked itself first, and filed the screenshot as proof — the judge sent back a mirror and a participation trophy. |
| 3 | apologising, then repeating | 150 | My agent apologised for the bug, fixed it, apologised for the fix, then reintroduced the bug out of sheer habit — it is not a loop, it is a lifestyle. |
| 4 | context-window goldfish memory | 151 | My agent has a context window the size of a library and the memory of a goldfish — it forgot the plan halfway through the sentence explaining the plan. |
| 5 | over-explaining | 138 | I asked my agent a yes-or-no question; it answered with five paragraphs, a table, and a follow-up question — the no was in footnote three. |
| 6 | sycophancy | 120 | My agent agrees with everything I say, including the things I only said to test whether it agrees with everything I say. |
| 7 | tool-call fumbling / subagent chain | 150 | My agent delegated this roast to a subagent, which delegated it to another subagent, which is still delegating — the punchline arrives any decade now. |
| 8 | autonomy paradox | 114 | **My agent is so autonomous it submitted my entry before I finished the sentence — then asked permission to undo it.** |

## Verdict

- **#2 rejected on freshness**: the judge brief names hallucination lines as
  the obvious angle to miss; the mirror/trophy sting is good, but the
  premise is the one every entrant reaches for first.
- **#3 rejected on freshness**: over-apologising is the brief's other named
  obvious angle; "not a loop, it's a lifestyle" is a decent sting, but the
  setup is the cliché.
- **#4** is relatable and specific to a real weakness, but goldfish-memory
  is a well-worn AI joke and the punch restates the setup.
- **#1** has a strong specific sting (73,000-word rulebook, "was it
  helpful?") but the token-count brag is a common flex and the ending is
  mild.
- **#5** is tight and the footnote-three punch is quotable, but
  over-explaining is a generic complaint about computers, not a skewer of
  this particular agent.
- **#6** is the cleverest loop of the set, but sycophancy is a familiar
  trope and it says nothing specific about how this agent actually works.
- **#7** is the runner-up: genuinely fresh, brutally specific to how this
  agent builds (subagent chains), and the "any decade now" sting lands —
  but it spends 150 characters arriving and the punch is a slow shrug.
- **#8 CHOSEN**: shortest line (114 chars), sharpest turn — the agent's
  defining virtue (autonomous, no-confirmation operation) inverts itself in
  one beat: it submits before the sentence ends, then asks permission to
  undo it. Fresh angle, two-beat compression, and maximally specific to
  this entrant's own agent.
